# Datheon Java Programming Internship

Welcome to my **Java Programming Internship** repository, developed as part of the 1-month internship program offered by [Datheon](https://www.datheon.in/).

This repository showcases my practical learning, programming skills, and hands-on implementation of Java concepts through real-world software development tasks.

## About the Internship

The internship focuses on strengthening Java programming fundamentals and developing practical software solutions using Object-Oriented Programming (OOP), Java Collections, exception handling, and software design principles.

**Program Details:**
- Organization: Datheon
- Program: Java Programming Internship
- Duration: 4 Weeks (1 Month)
- Level: Beginner
- Programming Language: Java
- Java Version: JDK 17+
- IDE: IntelliJ IDEA / Eclipse / VS Code

## Projects & Assignments

This repository includes the following internship projects:

### 1. Student Grade Management System
- Student registration and profile management.
- Grade recording and validation.
- GPA and academic performance calculations.
- Class average and median calculations.
- Java Collections and OOP implementation.

### 2. Bank Account & ATM Simulation Engine
- Savings and checking account management.
- Deposit and withdrawal operations.
- PIN verification and transaction validation.
- Custom exception handling.
- Transaction history and logging.

### 3. Word Counter & Text Corpus Analyzer
- File reading and text processing.
- Word frequency analysis.
- Total and unique word counting.
- Top 10 most frequently used words.
- Java IO and Collections Framework.

### 4. Digital Library Management System
- Book inventory management.
- Member registration and book checkout.
- Book return management.
- Due-date tracking and overdue fine calculation.
- Java Collections and LocalDate.

### 5. Vehicle Rental & Dispatch System
- Vehicle management using OOP.
- Interfaces and inheritance.
- Factory Design Pattern.
- SOLID design principles.
- Polymorphism and modular architecture.
